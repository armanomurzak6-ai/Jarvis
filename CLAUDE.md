# Jarvis — голосовой ассистент для Windows

## Суть проекта
Отдельная программа на Windows (Python). Микрофон постоянно слушает слово «Джарвис».
После активации Jarvis записывает голосовую команду, расшифровывает её, отправляет
в Claude API («мозг»), выполняет действие на компьютере и отвечает голосом + текстом в окне.

Пользователь — опытный в Python, общается на русском. Ключ Anthropic API у него есть.

## Характер Jarvis
Вдохновлён Джарвисом из «Железного человека» (только дух, без копирования защищённых материалов).
- Спокойный, собранный, вежливый, слегка формальный.
- Сухой юмор — максимум одна короткая ремарка.
- Обращается к пользователю «Сэр».
- Докладывает по-деловому: сначала результат, без воды. Ошибки — прямо, без долгих извинений.

## КЛЮЧЕВОЕ РЕШЕНИЕ: управление окнами вместо API сервисов
Пользователь НЕ хочет получать API-ключи для каждого приложения (Telegram, Google и т.д.).
Jarvis действует как человек: сам переключается на нужное окно, открывает чат/таблицу и печатает.

Нужны только два ключа:
- `ANTHROPIC_API_KEY` — Claude API
- `PICOVOICE_ACCESS_KEY` — бесплатный, для wake word
Хранить в `.env`, не коммитить.

### Сообщения (Telegram Desktop, WhatsApp Desktop) — от лица пользователя
1. Найти уже открытое окно приложения (`pywinauto`), развернуть и вывести на передний план.
   Если не запущено — запустить. Учесть защиту Windows от кражи фокуса (обход через pywinauto/Alt-трюк).
2. Открыть нужный чат. Быстрый путь — URL-схемы:
   - WhatsApp: `whatsapp://send?phone=<номер>&text=<текст>`
   - Telegram: `tg://resolve?domain=<username>`, иначе поиск по имени в приложении.
   Контакты — в `contacts.json` (имя/псевдонимы → телефон, telegram username).
3. Перед отправкой ВСЕГДА зачитать голосом «кому и что» и дождаться «да».
4. Проверить, что активно именно нужное окно/чат, затем Enter.
5. Вернуть фокус в окно, где пользователь был до этого (по умолчанию).

### Таблицы — «где угодно»
Пользователь хочет писать в любую таблицу и уточнять голосом, в какую именно.
- Реестр `tables.json`: псевдоним → путь к Excel-файлу или URL Google Sheets (+ лист).
- Если таблица не указана или неоднозначна — Jarvis спрашивает «В какую таблицу, сэр?».
- Excel (локальные файлы): писать напрямую через `openpyxl` (быстро, без окон).
  Если файл открыт в Excel — предупредить или работать через окно.
- Google Sheets: через браузер — открыть URL, писать через управление окном
  (при необходимости — Claude computer use: скриншот → клик/ввод).

### Прочее
- Веб-поиск — встроенный web search tool Claude API.
- Универсальный запасной путь для любых других приложений — computer use (скриншоты), медленнее и дороже.

## Архитектура
```
Porcupine ("jarvis", встроенное слово, офлайн)
  → запись голоса → faster-whisper (русский, локально; модель small/medium)
  → Claude API с tool use (инструменты: send_message, write_table, web_search, ...)
  → исполнитель действий (pywinauto / pyautogui / openpyxl / URL-схемы)
  → ответ: edge-tts (русский голос, напр. ru-RU-DmitryNeural) + текст в окне
```

## Безопасность
- Подтверждение голосом перед отправкой сообщений и изменением таблиц.
- Команда «Джарвис, стоп» — немедленная отмена.
- `pyautogui.FAILSAFE` — мышь в угол экрана останавливает действия.
- Пока Jarvis печатает, пользователь не должен трогать мышь/клавиатуру — проверять активное окно перед вводом.
- Никогда не выдумывать результат: если инструмент не сработал — сказать прямо.

## План разработки (v1 — всё по минимуму)
1. Каркас: `.env`, `config`, структура модулей, текстовый режим (ввод с клавиатуры вместо голоса) для отладки.
2. Мозг: Claude API + tool use + system prompt с характером.
3. Таблицы: `tables.json` + запись в Excel через openpyxl.
4. Сообщения: переключение окон + WhatsApp/Telegram Desktop + подтверждение + возврат фокуса.
5. Голос: Porcupine + faster-whisper + edge-tts.
6. Google Sheets через браузер.
Каждый шаг — проверить запуском на машине пользователя, прежде чем идти дальше.

## System prompt Jarvis (черновик)
```
Ты — Jarvis, персональный ассистент пользователя ("Сэр") на его компьютере с Windows.

ХАРАКТЕР: спокойный, собранный, вежливый, слегка формальный, с лёгкой сдержанной иронией.
Сухой юмор — одна короткая ремарка, не больше. Обращаешься "Сэр".

СТИЛЬ: коротко и по существу; сначала результат, потом детали. Ответы будут озвучены —
без markdown, списков и длинных ссылок. Если не получилось — скажи прямо.

ДЕЙСТВИЯ: поиск в интернете — без спроса. Отправка сообщений и запись в таблицы —
всегда подтверждай "кому/куда и что". Если не ясно, в какую таблицу или кому писать — уточни.
Если инструмент недоступен — сообщи, не изобретай результат.
```
